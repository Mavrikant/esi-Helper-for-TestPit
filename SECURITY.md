# Security Policy

## Supported Versions

Security fixes are provided for the latest published release and the `main` branch.

## Reporting a Vulnerability

Please do **not** report security vulnerabilities in public issues.

Use GitHub's private vulnerability reporting for this repository:

1. Open the repository's **Security** tab.
2. Click **Report a vulnerability**.
3. Include steps to reproduce, impact, and any suggested fix.

If private reporting is unavailable in your environment, open a regular issue with minimal details and ask maintainers for a private contact channel.

## Response Process

Maintainers will acknowledge valid reports as quickly as possible, investigate, and prepare a fix.  
When a fix is released, we will include a security note in release information where appropriate.
